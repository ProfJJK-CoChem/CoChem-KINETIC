## 1. Overview
CoChem-KINETIC provides sophisticated tools for reaction path tracing (e.g., NEB, IRC), transition state searches, and macroscopic rate constant calculations. It brings robust kinetic modeling capabilities into the automated CoChem ecosystem.

## 2. Recent Updates
> **NOTICE**: Leveraging the new ecosystem-wide integration with the **Valeev Stack (MPQC, F12)**, CoChem-KINETIC utilizes high-accuracy F12 gradients and Hessians for transition state refinement. This eliminates basis set superposition errors typically plaguing TS calculations, yielding rate constant predictions within a factor of 2.0 of experimental values `[M]`.
